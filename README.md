# Earthquake-Damage-Prediction-using-MLP-
Predicts structural damage from Nepal earthquake using a Multilayer Perceptron with K-Fold Cross Validation — covers full ML pipeline from preprocessing to evaluation.

This project applies a Multilayer Perceptron (MLP) neural network to classify building damage levels caused by earthquake in Nepal dataset from Kaggle. The pipeline includes data cleaning, feature normalization, and K-Fold Cross Validation to ensure robust, generalizable results. Model performance is measured across Accuracy, Precision, Recall, F1-Score, Confusion Matrix, and ROC-AUC — making it a thorough end-to-end classification study.
